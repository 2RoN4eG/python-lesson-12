# 3. Функция fight() — бой между двумя воинами

## Подробная механика боя

### 1. Первый воин атакует первым
- Второй воин получает урон, равный **attack** первого.
- Если у второго есть особенности (уклонение, защита, ярость и т.п.), они применяются.

### 2. Применение урона
- Урон вычитается из `health`:  
defender.health -= damage

- Если урон был заблокирован/уменьшен — применяется модифицированное значение.

### 3. Проверка на смерть
- Если `health <= 0`, воин считается погибшим, бой заканчивается.

### 4. Ответный удар
- Если второй выжил — он атакует первого по тем же правилам.

### 5. Цикл
- Раунды повторяются, пока один из воинов не погибнет.

### 6. Возврат результата
- `True` — победил первый воин.
- `False` — победил второй.

## Класс Battle
Метод:
**fight**(army1, army2) — сражение армий.

## Подробное описание сражения армий
### Выбор бойцов:  
Из каждой армии берётся первый живой воин (по порядку добавления).
### Дуэль:  
Между выбранными воинами проводится обычный бой fight(first, second):
- первый атакует,
- затем (если жив) отвечает второй,
- бой продолжается, пока один из них не погибнет.
### Смена бойцов:
- Если погиб воин из army1 — на его место выходит следующий воин этой армии. 
- Если погиб воин из army2 — выходит следующий воин второй армии.
- Атаку в следующем поединке начинает воин вставший на замену погибшего
### Окончание боя армий:
- Если в одной из армий закончились живые воины, эта армия считается проигравшей.
- Бой завершается. battle.fight(army1, army2) 
    + возвращает True, если победила army1
    + возвращает False, если победила army2.
